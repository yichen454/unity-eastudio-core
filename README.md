# EAStudio Core (`com.eastudio.core`)

Core utilities and shared infrastructure for EAStudio Unity projects.

## Installation

### Via Git URL
In Unity Package Manager (`Window` -> `Package Manager` -> `+` -> `Add package from git URL...`):
```text
https://github.com/yichen454/com.eastudio.core.git
```

Or add it directly to `Packages/manifest.json`:
```json
"com.eastudio.core": "https://github.com/yichen454/com.eastudio.core.git"
```
